# Changelog

## 0.2.0 (2026-11-13)

- Add Packagist, pub.dev, Hex, CRAN, Bioconductor and vcpkg package adapters.
- Add GHCR owner and GitLab project container discovery, reusing verified OCI inspection.
- Enable Homebrew casks as a separate default source.
- Preserve Composer dependency categories, Dart SDK constraints, Hex optional dependencies, R dependency classes, and vcpkg versions, port revisions, features and baselines.
- Support pinned vcpkg archives and local Git/filesystem registry metadata imports without executing recipes.
- Extend deterministic fixtures, SQL assertions, live checks and metadata analyst tasks.

## 0.1.0 (2026-11-13)

Initial release: 13 package ecosystems, Docker Hub and Quay, optional source-scoped credentials, prepared SQLite snapshots, and standalone executables for four platforms.

Targets: @query-farm/vgi 0.50 · VGI protocol 3.3 · Haybarn 2.0.0rc11 · vgi-lint-check 2.x (unpinned)
